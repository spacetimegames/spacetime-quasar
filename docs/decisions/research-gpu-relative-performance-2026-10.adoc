Caveats:

* Time Spy is a DX12 synthetic test. Integrated GPUs may behave differently in real games because of shared memory bandwidth.
* Time Spy does not expose 8 GB VRAM limits.
* Re-measure with our own deterministic benchmark replay (xref:pd-06-determinism.adoc[PD-06], xref:pd-08-development-order.adoc[PD-08]) before treating any of these as binding.
