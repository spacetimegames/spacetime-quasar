*CI vs. local split.*

* *GitHub CI (no GPU)* covers:
** `fmt`, `clippy`, unit and doc tests;
** Windows, macOS and wasm32 builds (the only builds we get for macOS and Windows without hardware);
** the cross-platform determinism hash comparison (xref:pd-06-determinism.adoc[PD-06]);
** renderer correctness on lavapipe (software Vulkan): shader validation and low-resolution golden images.
* *Local gates on the dev machine (real GPU)* cover:
** performance (benchmark replay);
** the VRAM cap;
** beauty corner and art-pass screenshots;
** runs on COSMIC/Wayland.
+
The Orchestrator runs them and attaches the results as evidence to the Jira issue.

* *No self-hosted runner* on the product owner's machine: the repo is public, and fork PRs could execute code on it.
