== Status

One of `Proposed`, `Accepted`, `Superseded by ADR NNNN`, `Deprecated`.

== Date

YYYY-MM-DD (the day the status last changed).

== Context

The problem, the forces at play and the constraints that bind the decision
(charter rules, earlier ADRs, measured facts).
Facts taken from outside the repository carry the date they were verified.

== Decision

What is decided, stated so that a Builder can implement it without asking.
Use exact values (versions, names, paths relative to the repository or to
`<workspace-root>`).

== Alternatives considered

Each serious alternative, and why it lost.

== Consequences

What becomes easier, what becomes harder, what follow-up work is created,
and what would make us revisit the decision.

== References

Links to sources, related ADRs and Jira keys.
