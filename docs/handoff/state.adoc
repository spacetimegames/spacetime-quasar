== What works

All of this is on `main`.

* Dev shell: `nix develop` gives the pinned Rust 1.99.0 plus mold and sccache (xref:../adr/0001-toolchain-msrv-nix.adoc[ADR 0001], xref:../adr/0004-build-resources.adoc[ADR 0004]). `nix fmt` works.
* Cargo workspace: 12 `st-*` crate stubs, `tools/xtask` and `apps/spacetime-quasar` (a stub binary). It builds and passes fmt, clippy with `-D warnings`, and tests. It also checks on wasm32.
* CI (GitHub Actions) runs 9 required checks: `fmt`, `test (linux-x86_64)`, `test (windows-x86_64)`, `test (macos-aarch64)`, `wasm32`, `msrv`, `deny`, `docs` and `nix`. See xref:../adr/0003-ci-design.adoc[ADR 0003].
* Docs: the xref:../index.adoc[index] and stubs, ADRs 0001 to 0004, the product decision records PD-01 to PD-26, `AGENTS.md`, `README.adoc` and the xref:../60-contributing.adoc[contributing guide].

== In progress

* ADR 0005 brings wgpu forward to Phase 0 so the window becomes visible on Wayland (PR #9).
* The empty window (SPAC-96, PR #7) waits on that ADR.

== Next

Remaining Phase 0 work:

. Empty window visible on Wayland that resizes and closes cleanly, started with `nix run`.
. Flake `packages.default` with runtime library wrapping, and flake `checks`. These come after the window lands. They make `nix run` start the game binary and give `nix flake check` the CI gates.
. This file (SPAC-28).
. The Phase 0 hands-on test note `docs/handoff/try/phase-0.adoc` and the owner test.
. The phase-gate review.

Phase 1 (Base crates) needs these ADRs:

* `nalgebra` vs `glam` boundary.
* Large-world coordinates and f32 vs f64. It uses the answered space-scale decision (PD-26).
* Determinism implementation.
* Command log and replay format.
* Data schema versioning.

== Known problems

* `nix run` does not work yet: the flake has no `packages` output.
* On NixOS the binary needs the dev shell to find the Wayland and X11 libraries, until the package wrapper lands.
* MSRV 1.88 is verified only in CI.
* The `nix` CI job only evaluates the flake until `checks` exist.
